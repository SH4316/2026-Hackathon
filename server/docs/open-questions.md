# 미결 사항

## 모델·장비 (팀 확인 필요)

- [ ] "4GB 모델"의 의미: 모델 파일 ~4GB / 4B 파라미터 / VRAM 4GB 실행 중 무엇인가
- [ ] 실행 장비의 RAM, GPU 유무·VRAM, OS
- [ ] 실행 환경 인터넷 사용 가능 여부(폐쇄망이면 이미지·모델 사전 반입 절차 필요)
- [ ] 런타임: Ollama vs llama.cpp server
- [ ] 정책상 모델 검사를 필수로 할지(`model_required`)

## 규칙

- [ ] 시스템 로그·설정 키: 지원할 제품·키 이름·형식 목록
- [ ] 공개 도메인 탐지 범위(현재는 URL 과 내부 접미사 `.internal/.local/.corp/.lan/.intra` 만)
- [ ] 국가별 형식 확장 우선순위(현재 한국 형식만)
- [ ] 더미·예시 값(예: `AKIAIOSFODNN7EXAMPLE`) 예외 처리 여부 — 사용자 표기만으로 예외를 주지 않음
- [ ] 조직 정책 항목: 프로젝트명·기밀 표식 사전(YAML) 형식

## 평가
