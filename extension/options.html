대시보드 연결

연결 안 됨

관리자가 대시보드 사람 화면에서 발급한 일회용 연결 정보(검사 서버 주소#코드)를 그대로 붙여 넣으면 서버 주소 저장과 연결을 한 번에 합니다. 코드만 받았다면 아래 검사 서버 주소를 먼저 저장하세요. 연결하면 개인 토큰이 API 키 자리에 저장되고, 검사 기록이 조직 대시보드에 내 이름으로 집계됩니다.

같은 PC면 루프백(127.0.0.1), 다른 서버면 조직 내부의 HTTPS 주소를 사용하세요.

이 브라우저의 확장프로그램 저장소에만 보관됩니다. 서버가 인증을 끈 개발 모드라면 비워 두세요.

텍스트·코드·PDF(글자 있는 것)에 민감정보가 있으면 위치를 보여 주고 "그래도 진행할지" 묻습니다. 읽을 수 없는 파일도 "안전한지 알 수 없지만 진행할지" 묻는데, 이 옵션을 켜면 묻지 않고 막습니다.

내 정규식 규칙

조직 규칙 외에 이 브라우저에서만 추가로 찾을 형식(사번·과제번호 등)을 정합니다. 서버 판정에 더해 판정을 강화만 하며, 조직 규칙을 끄거나 약하게 만들 수는 없습니다. 규칙은 이 브라우저에만 저장되고 서버로 보내지 않습니다.

    아직 추가한 규칙이 없습니다.

    Python 정규식 문법(\d \w 는 한글 등 Unicode 포함). 이름 그룹·인라인 플래그·역참조·중첩 수량자((a+)+)는 쓸 수 없습니다.

    치환하면 [MY_EMP_ID_1] 처럼 바뀝니다.
