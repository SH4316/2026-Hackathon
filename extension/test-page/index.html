Prompt Guard 테스트 채팅

실제 AI 사이트 대신 쓰는 시험용 페이지입니다. 아래 "전송된 메시지"에 기록되는 것이 외부 AI로 나갔다고 가정한 내용입니다. 예시 값은 모두 가짜입니다.

전송 대상 AI(시뮬레이션)

예시 프롬프트

버튼을 누르면 아래 두 입력창 중 마지막으로 선택한 곳에 들어갑니다.

입력창 A · textarea (Enter 전송, Shift+Enter 줄바꿈)

입력창 B · contenteditable (ChatGPT·Claude 방식)

입력창 C · 비동기 상태 편집기 (ChatGPT ProseMirror+React 방식)

화면(DOM)이 바뀐 뒤 잠시 후에 내부 상태를 갱신하고, 전송할 때는 내부 상태를 보냅니다.

입력창 D · 붙여넣기를 직접 처리하는 편집기 (Gemini·Quill 방식)

붙여넣기를 가로채 내용을 직접 넣고 input 이벤트를 내지 않습니다. 붙여넣은 뒤 다른 입력이 없어도 신호등이 갱신되어야 합니다.
