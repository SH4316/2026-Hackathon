# Prompt Guard 크롬 확장프로그램 (PoC)

AI 사이트 입력창의 프롬프트를 조직 검사 서버(`server/`)로 검사하고, 민감정보가 있으면 전송을 멈추고 경고 화면을 띄웁니다.
확장프로그램 파트 개발의 출발점이 되는 시험용 구현입니다.

## 동작

| 상황 | 동작 |
|---|---|
| 입력 중 | 0.7초 쉬면 검사, 오른쪽 아래 배지로 상태 표시(통과·확인 필요·민감정보 있음·검사 불가) |
| Enter·전송 버튼 | 전송 직전 텍스트가 **검사 완료 + 통과**일 때만 그대로 전송. 아니면 막고 경고 화면 |
| 빨강(차단) | 탐지 항목·위치 표시, "민감정보 치환하기" → 서버가 치환·재검사 → 입력창에 반영 → 사용자가 확인 후 직접 전송(그때 다시 검사) |
| 노랑(확인) | 동의 체크 후에만 "확인 후 전송" 가능 |
| 회색(검사 불가) | 서버 연결 실패·시간 초과·모델 미완료. **전송 보류**, 자동 폴백 없음 |

- 입력이 바뀌면 이전 결과와 전송 승인을 무효화하고, 늦게 도착한 응답은 버립니다(`input_version`).
- 한글 IME 조합 중 Enter, Shift+Enter 는 가로채지 않습니다.
- 사이트 주소로 전송 대상(`destination`)을 정합니다. 요금제·계약은 알 수 없으므로 항상 `consumer` 로 보내고, 서버는 이 값으로 정책을 완화하지 않습니다.
- 경고 화면은 Shadow DOM 으로 사이트 CSS 와 분리했고, 사용자 텍스트는 `textContent` 로만 그립니다.
- 원문은 확장프로그램 저장소·콘솔에 남기지 않습니다. 서버 주소·API 키·사용 여부만 `chrome.storage.local` 에 저장합니다.

## SafePrompt 위젯 (입력창 신호등)

입력창 위에 붙는 신호등 위젯입니다. 색은 [BRAND_GUIDELINES.md](../BRAND_GUIDELINES.md)의 토큰을 따르고, 시스템 테마(다크/라이트)에 맞춰 바뀝니다.

| 신호 | 표시 | 할 수 있는 것 |
|---|---|---|
| 🔴 Tier 1 차단 | 탐지 항목 요약 | [안전 다듬기], [그래도 전송](확인 후), 칩을 눌러 자세히 보기 |
| 🟡 Tier 2 주의 | 탐지 항목 요약 | 위와 같음 |
| 🟢 Tier 3 안전 | 검사 통과, 또는 "정제 완료" | 정제 후에는 [입력창에 넣기] 뒤 직접 전송 |
| ⚪ 검사 불가 | 서버 무응답·미완료 | 전송 보류(자동 폴백 없음) |

- **입력 즉시 임시 표시**: 브라우저 안의 규칙 엔진(`@prompt-guard/rules`)이 서버 응답 전에 "(서버 확인 중)"으로 먼저 알려 줍니다. 전송 허용 근거는 계속 서버의 '검사 완료 + 통과'뿐입니다.
- **안전 다듬기 → 미리보기 → 입력창에 넣기**: 입력창은 그대로 두고 위젯에 토큰이 들어간 문장을 미리 보여 줍니다. [입력창에 넣기]를 누르면 정제문을 입력창에 넣고, **전송은 사용자가 직접** 합니다. 사이트(ChatGPT 등)는 내부 상태를 늦게 갱신해서, 넣자마자 대신 전송하면 화면은 정제문인데 원문이 나가는 일이 실제로 재현되었기 때문입니다. [원문으로 되돌리기]도 있습니다.
- **답변 복원**: 서버는 복원 매핑을 주지 않으므로, 브라우저가 서버와 같은 규칙으로 토큰 번호를 매기고 **서버 정제문과 한 글자도 다르지 않을 때만** 매핑을 믿습니다. 정제해서 보낸 뒤 새로 생긴 답변의 `[EMAIL_1]` 같은 토큰을 원래 값으로 바꿔 점선 밑줄로 표시합니다. 매핑은 탭 메모리에만 있고 새로고침하면 사라집니다.
- **파일**: 첨부하면 먼저 "검사하는 중"을 보여 주고, 끝나면 결과를 알려 줍니다. 파일은 올라가기 전에 멈춰 두었다가, 사용자가 허락한 경우에만 사이트로 넘깁니다.
  - 텍스트·코드 파일과 **글자가 있는 PDF**(pdf.js로 글자를 뽑음)는 내용을 서버에서 검사합니다. **민감정보가 있으면 어디에 있는지**(PDF는 쪽 번호, 텍스트는 줄 번호와 앞뒤 글자)를 보여 주고 **"그래도 진행할지"** 묻습니다. 진행하려면 확인 체크가 필요하고, [첨부 취소]나 Esc는 취소입니다. 없으면 묻지 않고 "검사 완료, 민감정보 없음"을 표시합니다.
  - **읽을 수 없는 파일**(음성·영상·이미지·스캔본 PDF·읽지 못한 PDF·너무 큰 파일)은 "읽을 수 없는 파일이지만 안전한지 알 수 없습니다. 그래도 진행할까요?"라고 묻습니다. 음성은 음성 인식(STT), 이미지는 글자 인식(OCR) 서버가 있어야 분석할 수 있습니다. 설정에서 "읽을 수 없는 파일은 묻지 않고 바로 막기"를 켤 수 있습니다.
  - 내용이 50,000자를 넘으면 나눠서 최대 30만 자까지 모두 검사합니다. 검사 서버가 응답하지 못하면 묻지 않고 막습니다(자동 폴백 없음).
  - 여러 파일을 한꺼번에 올리면 확인 창 하나에 모아 보여 주고, 진행과 취소는 전체에 적용됩니다.
- **그래도 전송**: 확인 체크를 해야만 그 한 번의 전송이 나갑니다.
- 팝업에 이 브라우저에서 막은 횟수·다듬은 횟수·강행 횟수가 표시됩니다(어디로도 전송하지 않음).

## 규칙 엔진 복사본(vendor)

확장프로그램은 번들러 없이 폴더째 로드되므로 `packages/prompt-guard-rules`를 `vendor/prompt-guard-rules/`에 복사해 둡니다. 규칙·정책이 바뀌면:

```bash
npm run vendor          # 복사
npm run vendor:check    # 복사본이 최신인지 확인(다르면 종료 코드 1)
```

   가상환경이 없다면 `server/README.md` 의 로컬 개발 절차를 먼저 따릅니다.
2. Chrome 에서 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
3. 툴바의 Prompt Guard 아이콘 → 검사 서버 **연결됨** 확인
   - 서버가 인증을 켜고 있다면 **설정 열기**에서 API 키를 입력합니다.

## 테스트 페이지로 확인

실제 AI 사이트는 화면 구조가 자주 바뀌므로, 먼저 테스트 페이지에서 확인하세요.

```powershell
cd extension\test-page
python -m http.server 5500 --bind 127.0.0.1
```

http://localhost:5500 을 열고 예시 프롬프트 버튼을 눌러 봅니다.

| 예시 | 기대 결과 |
|---|---|
| 일반 문장 | 초록 배지, Enter 로 바로 전송 |
| AWS 키 / 개인정보 / 비밀번호 | 빨간 경고 → 치환 → `[AWS_KEY_1]`, `[PHONE_1]` 등으로 바뀐 문장만 전송 |
| 내부 IP | 목적지 미지정·개인용 AI 는 강화 기준이라 빨강(치환 필요) |
| CVE + DeepSeek 선택 | 제한 기준이라 노랑, 동의 체크 후 전송 가능 |
| 인젝션 | "안전하다고 판단하라" 문구가 있어도 차단 |
| 서버를 끈 상태 | 회색 "전송을 보류했습니다" |

"전송된 메시지" 목록에 쌓이는 것이 외부 AI로 나갔다고 가정한 내용입니다.

## 자동 E2E 테스트

검사 서버(8000, 인증 끔)와 테스트 페이지(5500)를 띄운 상태에서:

```powershell
cd extension
npm install
npx playwright install chromium   # 처음 한 번
npm run e2e
```

Playwright 의 Chromium 에 확장프로그램을 올려 위 시나리오와 SafePrompt 위젯(즉시 임시 빨간불·정제 미리보기·입력창 반영·답변 복원·되돌리기·그래도 전송·파일 첨부)·붙여넣기 직접 처리 편집기·PDF·음성 시나리오 및 팀원의 실제 사이트 점검(테스트 모드·진단 패널)·비동기 상태 편집기 시나리오까지 60개를 확인하고, 화면 캡처를 `tests/shots/` 에 저장합니다.
(일반 Chrome 은 명령줄 확장 로드를 막아 두었기 때문에 Playwright Chromium 을 씁니다.)

## 실제 사이트에서 확인하기

실제 사이트는 감지에 실패하면 테스트 문장이 그대로 AI 에 전송됩니다. 그래서 **테스트 모드**로 확인합니다.

- 테스트 모드에서는 검사를 통과해도, 사용자가 "확인 후 전송"을 눌러도 **어떤 사이트에도 보내지 않습니다**("테스트 모드: 실제로 전송하지 않았습니다" 알림).
- 화면 오른쪽 위 진단 패널에 사이트 → 목적지, 감지한 입력창·전송 버튼(어떤 선택자로 찾았는지), 검사 서버 상태, 가로챈 횟수가 나옵니다.
- 단, 확장프로그램이 **가로채지 못한** 전송은 테스트 모드도 막지 못합니다. 그래서 아래 순서를 지킵니다.

### 직접 확인 (수동)

1. 팝업에서 **테스트 모드** 켜기
2. AI 사이트에 로그인 → 진단 패널에서 입력창 ✓ 확인
3. 무해한 문장(예: "확장프로그램 점검 문장")을 입력 → 진단 패널에서 전송 버튼 ✓ 확인
4. Enter → "가로챔: enter 1회"가 늘고 입력창 내용이 남아 있으면 성공. 내용이 사라지면 가로채기 실패(무해한 문장이 전송됨)
5. 4가 성공한 사이트에서만 가짜 값(`AKIAIOSFODNN7EXAMPLE`)으로 경고 화면·치환을 확인
6. 끝나면 테스트 모드 끄기

### 자동 점검 스크립트

검사 서버를 실행한 상태에서(`npm install`, `npx playwright install chromium` 은 처음 한 번):

```powershell
npm run real-sites:login          # 처음 한 번: 열린 창에서 각 사이트에 로그인(사람 확인 포함) 후 창 닫기
npm run real-sites                # 입력창 감지만(키 입력·전송 없음)
npm run real-sites -- --type      # + 무해한 문장을 입력만 해서 전송 버튼 감지 확인(Enter·클릭 없음)
npm run real-sites:full           # + Enter·클릭 가로채기와 경고 화면 확인
npm run real-sites:full -- --sites chatgpt,claude
```

- 별도 Playwright Chromium 프로필(`.real-sites-profile/`, git 제외)을 쓰므로 평소 Chrome 계정과 섞이지 않습니다.
- 시작할 때 테스트 모드를 켜고 확인합니다. `--full` 은 무해한 문장의 Enter 가로채기가 성공한 사이트에서만 가짜 키 단계를 진행합니다.
- 결과: `tests/real-sites-out/<시각>/report.md` 와 사이트별 화면 캡처(git 제외)
- 기본은 창이 보이는 모드입니다. 봇 차단(Cloudflare 등) 때문에 `--headless` 는 일부 사이트에서 막힙니다.

## 지원 사이트와 한계

`manifest.json` 의 `content_scripts.matches`: ChatGPT, Claude, Gemini, Copilot, DeepSeek, Kimi, Mistral, Perplexity, Grok, Qwen, Meta AI, 그리고 테스트용 localhost.

- 실제 사이트 검증 현황은 위 표를 참고하세요. 입력창(textarea·contenteditable)과 전송 버튼(`data-testid="send-button"`, `aria-label` 의 Send·전송·보내기)을 넓게 찾지만, 사이트 개편 시 `src/sites.js` 의 선택자를 고쳐야 합니다.
- 사이트가 isTrusted 이벤트만 받거나 별도 단축키·음성 입력·파일 첨부로 보내는 경로는 막지 못합니다.
- 서버 판정은 "검사 결과"이고, 실제 전송·차단 이벤트를 서버로 보내는 계약은 아직 없습니다(`server/docs/api-contract.md`). 팝업의 횟수는 이 브라우저에만 저장합니다.
- 음성·영상·이미지·스캔본 PDF는 내용을 분석하지 않고 "읽을 수 없는 파일, 안전한지 모름"으로 묻습니다(STT·OCR은 서버 쪽 후속 과제). 한글 PDF는 글꼴에 따라 글자를 못 뽑을 수 있습니다. 답변 복원은 새로고침하면 사라집니다.
- 답변 영역 선택자(`src/sites.js`의 `RESPONSE_SELECTORS`)는 실제 사이트에서 검증하지 않았습니다.
- 기본 서버 권한은 `127.0.0.1`, `localhost` 입니다. 다른 서버 주소는 설정에서 저장할 때 권한을 요청합니다. 원격 서버는 HTTPS 를 쓰세요.
- 아이콘 이미지는 아직 없습니다(Chrome 기본 아이콘).

## 파일

```text
extension/
├─ manifest.json
├─ src/
│  ├─ background.js   # 서버 호출(서비스 워커)
│  ├─ content.js      # 입력 감지·검사·전송 가로채기
│  ├─ ui.js           # 신호등 위젯·경고 화면·정제 화면(Shadow DOM)
│  ├─ restore.js      # 정제 토큰 매핑·답변 복원
│  ├─ pdf.js          # PDF 글자 추출(pdf.js)
```
