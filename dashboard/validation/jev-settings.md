# 독립 Jev 프롬프트와 결과 태그 설정 검증

2026-10-30 UTC에 Java 21·Node.js 24.22.1·실제 MySQL 8.4.7과 별도 테스트 DB를 사용하는 패키지 서버 `http://127.0.0.1:8085`에서 확인했습니다. 이전 [태그 세부 정보](tag-details.md)·[태그별 Jev·Python 정규식](tag-rules.md) 기록과 결과 파일은 당시 검증으로 보존합니다.

## 변경 동작

사이드바의 `/settings/jev`는 선택한 버전의 독립 `jevPrompts`와 결과 태그 연결을 편집합니다. 한 프롬프트에서 부모·자식 등 여러 기존 태그를 출력할 수 있고, `tags[].jevThreshold`는 같은 태그를 사용하는 여러 프롬프트가 공유합니다. 임계값은 0 이상 1 이하, 소수점 여섯 자리까지 허용합니다. `null`은 미설정이고 `0`은 유효한 설정값이며 자동 기본값은 없습니다. 프롬프트·출력 연결·선택한 태그 임계값은 최신 버전 revision으로 원자적으로 저장합니다.

초안과 발행 버전 모두 Jev 설정을 편집할 수 있습니다. 출력 선택 해제·프롬프트 삭제는 태그와 임계값을 보존합니다. 전체 초안 저장으로 태그를 제거하면 해당 출력 연결만 제거하고 독립 프롬프트는 유지합니다. 복제는 프롬프트·연결·임계값을 보존하며 이후 각 버전은 독립적입니다. 메트릭 설정은 태그별 임계값을 편집하고 Jev 프롬프트는 전용 화면에서 편집합니다. 결과 태그의 링크는 `versionId`·`tagId`를 유지해 해당 태그 설정을 엽니다.

V7은 비어 있지 않은 기존 태그의 Jev 원문을 독립 프롬프트로 옮기며 공백·탭·줄바꿈만 있는 값도 보존합니다. 길이 0인 값은 프롬프트를 만들지 않고 임계값은 `null`로 유지합니다. 신규 프롬프트 생성은 버전당 100개까지 허용하며, 마이그레이션으로 이를 넘은 기존 설정도 삭제하지 않습니다. 태그의 이전 `jevPrompt` API 필드는 제거되어 엄격한 JSON 검증에서 거부합니다. 보관된 이전 DB 열과 V1~V6 마이그레이션은 유지합니다.

## 검증 범위와 재실행

자동 axe 검사는 제한된 설정 화면을 대상으로 하며 수동 보조 기술 검증이나 WCAG 전체 적합성 판정은 포함하지 않습니다. 외부 Jev·탐지기의 실제 실행, 점수 생성·임계값 적용, 설정 자동 재로딩과 Docker 이미지·컨테이너 실행은 이번 검증 범위에 포함하지 않습니다. 대시보드는 저장한 설정만 제공합니다. 실제 점수 생성과 설정된 임계값에 대한 `점수 >= 임계값` 판정은 연결하는 탐지기에서 구현·적용해야 합니다.

`dashboard/`에서 테스트 전용 로컬 서버를 명시해 재실행합니다. 이전 `smoke_jev_prompt.mjs`도 새 스크립트로 연결되며 기본 출력은 새 보고서입니다.

```bash
DASHBOARD_URL=http://127.0.0.1:8085 \
  BROWSER_REPORT=validation/jev-settings-browser.json BROWSER_SCREENSHOT_PREFIX=jev-settings \
  node scripts/smoke_jev_settings.mjs
```
