Published tag-detail correction (2026-10-30, current behavior): the tree remains versioned. Publishing freezes tag IDs, membership, parents and order, the version name, and policies. Name, color, description, examples, guidance, Jev prompt and Python regex remain editable for each tag in the currently selected draft or published version. A matching tag ID in a different version is unchanged. Saving the active published version's details preserves its ID and active status, increments its revision, and updates the next classifier-config response; external consumers must fetch and apply that revision.

Siblings with equal order use stable ASCII tag IDs as the tie-breaker, so renaming a tag cannot reorder the tree. Existing form groups, counters, font fallback, colors and mobile stacking are retained.
