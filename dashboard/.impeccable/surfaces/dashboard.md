Jev separation extension (2026-10-30, current behavior): `/settings/jev` edits independent version-scoped judgment prompts and their existing output tags. A prompt may select tags at any tree level; prompts referencing the same tag in one version share that tag's nullable Jev threshold. Blank is unconfigured, zero is valid, and thresholds accept 0–1 inclusive with up to six fractional digits, without defaults or parent inheritance. One save applies prompt text, output bindings and selected tags' thresholds atomically. Unselecting outputs or deleting a prompt preserves tags and thresholds. Removing a draft tag prunes its bindings; cloning preserves independent settings for later version-local edits. Published tree, version-name and policy locks remain; tag details and Jev settings stay editable.
