# AI 보안 관제

## Platform
web

## Product
외부 분류기가 전송한 Prompt, 감지 위치와 태그를 사용자 정의 트리 버전으로 요약하고 개인별 이력과 저장된 검색 결과를 확인하는 도구.

## Audience and task
한국어를 사용하는 보안 담당자. 전체 현황에서는 그래프로 탐지량을 확인한다. 상세 검색은 탐지 이력에서 수행하고 조건과 고정 결과를 보존한다. 실제 감지와 태그 부여는 외부 분류기가 담당한다.

## Constraints
Spring/Java 21/Gradle/MySQL와 React/TypeScript/Vite. 로그인 없이 실행하며 수동 새로고침을 사용한다. 사용자 정의 설정은 초안→발행→활성화로 관리한다. 발행 시 태그 ID·구성·부모·순서, 버전 이름과 정책을 고정하며, 태그 이름·색·설명·예시·판단 참고사항·Jev 프롬프트·Python 정규식은 현재 선택한 버전에서 계속 편집한다. 같은 태그 ID를 가진 다른 버전에는 적용하지 않는다. 활성 버전은 최대 하나이며 활성 버전의 세부 정보 저장은 다음 분류 설정 조회에 반영한다. 수집 당시의 태그 이름·색과 저장 검색의 이벤트 구성은 보존한다. 일반 신규 DB는 빈 상태이고 dev 전용 볼륨만 SQL 예시 데이터를 받는다. Prompt 원문과 Unicode 코드 포인트 기준 감지 영역을 저장한다. 외부 감지 엔진의 동작 설정은 준비 중으로 비활성화한다.

## Design commitment
승인된 계획의 밝은 한국어 관리자 UI. 전체 현황, 탐지 이력, 사람 관리, 메트릭 설정, 저장된 검색, 감시 연동을 일관된 내비게이션으로 연결한다. 장식보다 숫자와 표의 읽기 순서, 필터의 명확성, 상태 구별을 우선한다. 제작은 코드로 직접 진행한다.
