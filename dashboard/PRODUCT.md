# AI 보안 관제

## Platform
web

## Product
관리자가 AI 사용 시 수집된 정책 상태와 보안 감지 이벤트를 항목별 숫자와 사람별 이력으로 확인하는 로컬 시연용 도구.

## Audience and task
한국어를 사용하는 보안 담당자. 전체 현황을 확인하고 항목에서 이력으로, 이력에서 개인 기록으로 이동한다. 실제 감지는 외부 시스템이 담당한다.

## Constraints
Spring/Java 21/Gradle/MySQL와 React/TypeScript/Vite. 로그인 없이 로컬에서 실행한다. 수동 새로고침. 감시 설정은 열람만 가능하고 입력 및 저장은 비활성. 원문 대화나 실제 민감정보 값은 수집하지 않는다.

## Design commitment
승인된 계획의 밝은 한국어 관리자 UI. 전체 현황, 탐지 이력, 사람 관리, 감시 설정을 일관된 사이드 내비게이션으로 연결한다. 장식보다 숫자와 표의 읽기 순서, 필터의 명확성, 상태 구별을 우선한다. 제작은 코드로 직접 진행한다.
