SafePrompt는 자료형 보존 합성 치환(Type-Safe Synthetic Substitution)을 적용하여 숫자는 동형 스케일의 가짜 숫자로, 텍스트는 가짜 식별자로 변환해 파이썬/R 통계 분석 코드가 오류 없이 100% 실행되도록 보장합니다.

🔒

양방향 자동 복원 (Bi-directional Restore):
AI가 생성한 가짜 데이터 결과는 브라우저 렌더링 직전 온프레미스 매핑 테이블을 거쳐 원본 실험 수치로 안전하게 자동 복원됩니다.
